# Validation record

This file records validation of ShopFlow with real shop owners. **It contains
no session records yet.** The template below is for recording a real session
afterwards; do not fill it with expected, typical or invented answers.

## Three different things

| Kind | Means | Status for ShopFlow |
|---|---|---|
| **Workflow validation** | A shop owner describes how their business actually runs, and the product is shaped to fit it. Nobody uses the product. | **Done, informally**: the operating process of one electrical shop owner in Tamil Nadu (paper orders, manual stock checks, incomplete price knowledge, supplier credit, weekly turnover-based settlement) is stated in the README's "Real Shop Workflow". No session record exists below. |
| **Product pilot** | A real shop uses ShopFlow on its own orders, catalogue and suppliers, for a period, and what happens is measured. | **Not done.** |
| **Commercial validation** | Evidence that a shop would pay: a price asked and answered, a pre-order, a paid pilot. | **Not done.** No willingness-to-pay evidence exists. |

A README or pitch may only claim a row whose status here says it happened,
backed by a record below.
